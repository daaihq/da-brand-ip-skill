# 固定白底英文资产模板 v2

机器可读坐标见 `assets/layouts/layout.json`。坐标采用标称画布像素，输出其他分辨率时等比例缩放。模板SVG中灰色框和占位词仅用于定位，最终图不能保留。

本文件与 compose_board.py 仅用于三张基础资产；英文限制不适用于文章配图，应用文字按 content-use.md。

## 主形象设计卡 1024×1024

顶部名称中心(512,78)，最大宽870，默认字号54、最小28；副标题中心(512,114)，默认CHARACTER DESIGN / v2。主形象位(48,184,528,602)，素材底边基线778；MAIN CHARACTER基线160，中心x=312。

右侧SIGNATURE DETAILS基线160，中心x=790。特征区固定两列三行，每格172×152：左列x=608，右列x=800，行y=188/386/584；标签基线366/564/762。展示1—6项真实存在的衣物、配件、特殊道具或结构细节。无需服装的角色也可用外壳、耳部、尾巴等。未使用位纯白留空，不加虚构饰品，不重排剩余格子。

COLOR PALETTE中心(512,839)。固定七个124×54色块位，从x=48起，间距10，y=866；英文用途基线947，HEX基线974。实际使用5—7色，未用位纯白留空，色位不重新均分。主色／辅助色／强调色／皮肤／头发／金属／细节分别可用PRIMARY、SECONDARY、ACCENT、SKIN、HAIR、METAL、DETAIL；不存在的类别换为BODY、OUTFIT、OUTLINE等实际用途，不能添加不存在的材质或配色。单色角色可从真实存在的亮部／暗部／线条／中性色选取，并如实标注，不捏造五种主体颜色。

页脚基线1004。所有物件和标签限制在对应框内。主角色必须完整；特征单元可展示单件服装或局部结构，但不改变原设计。纯白背景RGB 255,255,255；固定区域之间的白空间不能填入花纹或装饰。

## 文字规则

所有图片可见文字默认英文，包含角色名、服饰上的字、道具上的字、标题、关键词、动作／表情／特征／色板标签和页脚。对话、规范说明与原文可用中文。英文标签建议1—3词，区块标题用统一大写与无衬线字体。中文品牌名或Logo无批准的英文版本时先问展示方式，不擅自创造官方译名或直接改变原标志。用户当次明确覆盖则优先当次要求。

长名称只在固定标题框内缩小；最小字号仍无法容纳时采用用户认可的英文简称，完整名称保留在资料说明或规范中，不挤动其他区域。不要照抄DAAI样例口号或模板占位词。脚本的ASCII检查只是防止非英文字符混入，不能替代英文语义、拼写与官方名称核对；使用普通英文标点。

## 生成与精度

生成前传入对应SVG模板的可查看渲染版本作为布局参考，或者明确写出坐标比例。图像生成的几何与文字可能漂移，模板并不保证模型逐像素遵守。

本版本以严格固定排版为目标，宿主允许时优先采用固定版式排版：独立生成所需角色素材，以同一layout.json图框放置，使用 `scripts/compose_board.py` 完成模板排版。此路径最终仍只交付三图，内部素材不另算交付。宿主限制程序化图像组合时遵循宿主要求，说明当前能达到的精度，不假装完全锁定。

固定模板排版接受白底的独立角色素材，不裁切一张多人拼图冒充独立素材；不变形或修改角色内容，只按图框缩放和摆放。三视图素材必须视角匹配；不能将正面镜像称为背面。

检查图框偏移、基线、文字截断、重叠、背景。直接生图路径偏差超过画布1%或发生遮挡时修正；精确排版路径检查框坐标与标签基线一致。输出SVG风格图不等于获得可编辑矢量角色，3D材质图不等于3D模型。

## 精确排版脚本

运行 `python scripts/compose_board.py --kind overview --spec board.json --font /path/to/font.ttf --out /path/to/03-overview.png`。需要Pillow和支持英文的字体。图中不接受中文标签；先整理英文展示文本，不得输出方框字。缺Pillow时采用宿主允许的其他排版工具。脚本拒绝覆盖已存在文件。

board.json字段：title、subtitle、tagline、info（最多4行）、keywords（最多4行）、actions_title、expressions_title、footer_left、footer_right；actions为5个对象、expressions为6个对象，每项包含file（独立素材绝对路径或相对JSON路径）、label。pixel_art=true时用最近邻缩放。所有文案来自已确认角色资料。

三视图kind=turnaround：title、subtitle、images（3项，每项file和label，正／左侧／背）；主图kind=main：title为已确认英文名，subtitle默认CHARACTER DESIGN / v2，images为1项file，details为1—6项file与英文label，palette为5—7项英文role与六位hex（例#2255AA）；details和palette可含slot（从0开始），指定固定位置，缺位不重排。footer_left／footer_right可选。源素材应紧凑但完整、白底、没有自带标题和标签，并统一脚底留白；脚本按图框底边对齐整个素材，不自动抠图、裁切或辨识脚底。排版后仍需人工检查视觉基线与主体一致性。

参考图用途必须分开：第一张设计卡左侧主体承担身份参考；特征单元帮助理解服饰结构，色板作为颜色规范；文字与版式不能复制进文章／宣传场景。能读取原始干净候选时优先使用，无法取得时明确仅使用设计卡左侧角色区。不得为便于引用而默认新增第四张正式资产。
