# 当前风格修订与 X 分享

从 `style-menu.md` 的124种风格中选择，完整执行对应的 `styles/<风格ID>.md`。用户实测来源25种保持版本优先级；有 preferred_prompt 时优先使用它，历史来源不覆盖执行版本。

用户明确要求修订 Skill 时才保存规则变更。保留稳定 ID，记录适配规则与版本；已确认角色不自动切换画风。基础资产遵循白底、英文标签与固定模板，内容应用文字跟随原文语言。

修订后验证个人角色和非人品牌角色的三图效果、动作表情、版式与身份一致性。没有实际生成就标未验证，不用文本审阅替代。

X 内容仅在用户请求时准备。可提供视觉卖点、适用角色或品牌、真实示例图说明、完整适配提示词和互动问题。标签和语气服从当次用户要求；不承诺未经测试的一致性，不假称已发布。
