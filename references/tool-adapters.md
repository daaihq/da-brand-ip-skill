# 宿主能力适配

使用当前宿主已暴露的内置图像生成／编辑能力。先看参考图；创建、修订均明确标注身份图、布局图、产品图的用途。遵守宿主图像技能与输出规范。无工具时输出完整提示词和规格，并说明尚未生图，不伪造路径。

## ChatGPT

使用原生生图与文件能力。图片由宿主自动展示／保存时按宿主规范处理，不为重复展示而下载上传。用户要求的是可携带资产包，若宿主允许导出原始生成文件，则在其授权范围内取得三张原始文件并登记；只能获得消息中的图片时如实说明未完成可携带文件包，不伪造本地文件。

运行包与候选内容文件按当前环境持久化文件规则保存。不能保证跨聊天自动识别当前角色；新会话通过资产包、已持久化引用或用户明确选择恢复。不能保证安装在ChatGPT中的Skill自动同步到独立Codex客户端。

## Codex

使用可写项目目录 `.da-brand-ip/` 或用户指定目录；不要写入Skill安装目录。可运行Python辅助脚本。`package_manager.py`使用Python标准库；固定排版脚本需Pillow及有中文覆盖的字体。缺依赖时用可用宿主排版工具，不能悄悄安装或降低为乱码字体。

用户提供有效API工作流时可适配其接口，不杜撰模型名、分辨率、参数或密钥，不把凭据写入资产包。没有图像能力则交付待执行提示词，而不是用程序绘画冒充生成。

## 精确排版边界

模板SVG是代码原生布局，不是生成角色。角色视觉由生图工具完成。固定图框的排版仅处理位置、缩放、英文文字与精确色板；如宿主对程序化图像处理有限制，遵守限制并使用其允许的路径。不要偷偷把低精度生成板标为像素级固定版式。
